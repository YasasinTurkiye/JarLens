# JarLens

**A Java decompiler with automatic deobfuscation, for Windows.**

JarLens opens compiled Java code (`.jar` files) and turns it back into readable source, cleaning up obfuscated names and structure along the way, so you can see what a JAR actually does.

## Download

Get the latest version of **[JarLens.exe](https://github.com/YasasinTurkiye/JarLens/raw/main/JarLens.exe)** (about 67 MB).

Or open `JarLens.exe` in the file list above and click **Download**.

> **Note:** Use the direct link above rather than **Code → Download ZIP**. The executable is stored with Git LFS, so the ZIP may only contain a small placeholder file instead of the real program.

## Usage

1. Download `JarLens.exe`.
2. Run it. No installation is needed.
3. Open the `.jar` file you want to inspect.

Windows SmartScreen may warn you because the executable is not code-signed. Click **More info → Run anyway** to start it.

## Requirements

- Windows 10 or 11 (64-bit)
